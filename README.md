Description:
CarInfo is a Flutter-based mobile application designed to allow users to explore detailed information about various cars. The app provides in-depth car details, including specifications, images, and features, helping users make informed decisions. With the ability to save favorite cars, users can easily keep track of their preferred models for quick access. Built using Clean Architecture principles, the app ensures modularity and scalability, making it easier to maintain and extend in the future. State management is efficiently handled with BLoC, providing a clear separation between business logic and UI components, ensuring a smooth and responsive user experience. CarInfo is not intended for buyers, but rather for users who are simply looking to explore and gather car information in a structured and intuitive way.
